# Khodiyar Grocery

Online grocery store with a customer storefront, an admin panel, a REST API
and a fully responsive mobile view.

## Structure

```
backend/    Node.js + Express REST API (JSON file database)
frontend/   Customer storefront (HTML, CSS, JS)
admin/      Admin panel for products, orders, customers, reports...
frontend/css/mobile/   Responsive styles for phones and tablets
```

## Run locally

```bash
cd backend
npm install
npm start
```

- Storefront: http://localhost:5000
- Admin panel: http://localhost:5000/admin
- API health: http://localhost:5000/api/health
